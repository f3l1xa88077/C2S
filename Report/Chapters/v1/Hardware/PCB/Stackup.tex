The board uses a four layer stackup of SIG, GND, VCC, SIG as according to most stackup guides like those from \href{https://www.advancedpcb.com/en-us/resources/blog/understanding-4-layer-pcb-benefits-designs/}{Advanced PCB}. Since the board does not include any high-speed signals, it is not necessary to have two reference planes for a reduced reference plane impedance like explained in this \href{https://electronics.stackexchange.com/questions/41470/the-best-stack-up-possible-with-a-four-layer-pcb}{Stack Exchange post}.
