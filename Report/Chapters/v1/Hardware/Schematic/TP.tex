Test points were added for all voltage levels of the schematic to verify that power was being delivered correctly during testing, as well as on the shutter (button output) to confirm that the input was being delivered, and both I2C lines if oscilliscope probing was required. More test points could not be added as all other signals are either high-speed or sensitive. I did not break out any 3V3 or GND headers as I had not used them in Version 0.1. No test point for VEPS was added since there was already a header that can be probed.
