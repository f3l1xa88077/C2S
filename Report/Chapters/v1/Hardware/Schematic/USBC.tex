As introduced in \autoref{sec:v1-schematic-power}, the USB-C connector is primarily used for power delivery. Alongside this main focus, the data lines have been connected to the STM32 to create a COM port to convert the board into a USB-cam - allowing the sensor to be controlled from an external computer to aid in debugging and testing, although, this scope is an extension of the system requirements and its functionality is not required for the USB-C subsystem to be considered a success.
