The \href{https://www.jaycar.com.au/green-push-on-style-knob/p/HK7711}{knob} I had that was meant to be used on the rotary encoder did not fit, so, I 3D modelled one in Fusion360.
I added some grip so it would be easier to rotate by following \href{https://www.youtube.com/watch?v=i3aDl9bQ-oY}{this YouTube guide}.
