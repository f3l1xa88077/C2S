The timer functionality maps to the audio buzzer system. As explored in \autoref{sec:buzzer}, the wrong circuit was used so the buzzer does not work.
You can opt out of enabling the timer.
If you wish to enable it, set 'Trigger Source' to 'Internal Clock', set 'PWM Generation CH1' and please refer to the \href{https://au.mouser.com/datasheet/3/6118/1/cbt_09427_smt_tr.pdf}{component datasheet} to calculate the required prescalar for the buzzer's frequency.
As the circuit is non-functional, I have not enabled it.
